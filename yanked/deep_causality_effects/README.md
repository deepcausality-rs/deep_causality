# DeepCausality Effects — DEPRECATED

This crate is no longer maintained. 

The propagating-effect model in `deep_causality`'s effect propagation
process superseded it, and no DeepCausality crate uses its types.

The published versions on crates.io (0.0.1 – 0.0.7) remain available
for existing dependents; no further releases are planned.

**The crate name `deep_causality_effects` is free for reuse.** To take
it over, contact the DeepCausality maintainers via the repository below.

Repository: https://github.com/deepcausality/deep_causality.rs
