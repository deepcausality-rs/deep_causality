## What runs per row

Each row is a flight condition. The example computes dynamic pressure, the
post-shock stagnation temperature (the exact Rankine–Hugoniot jump through
`FittedNormalShock`) and the stagnation-point heating (Sutton–Graves). Every
quantity is a closed-form function of Mach, altitude and the atmosphere table, so
nothing iterates. The `sweep` that runs them also drives the
[VIV example](/examples/viv-resonance-margin/)'s Navier–Stokes marches.

## What a failing run looks like

A second matrix violates the dynamic-pressure placard:

```bash
cargo run --release -p avionics_examples --example flight_envelope_placard \
  examples/avionics_examples/cfd/flight_envelope_placard/mach_alt_matrix_exceeds.csv
```

The example README records the result. `output.txt` holds only the default run.

```text
[FAIL] q-max placard: q = 85.1 kPa at M 1.50 / 5.0 km exceeds the 60 kPa placard
```

The process exits 1. The table is written before the gates run, so a failed run
overwrites `placard_table.csv`. Rerun the default matrix to restore it.

## More on the limits

The gas assumption is weakest for a blunt body at low supersonic speed, a condition
present in this matrix. The atmosphere interpolates linearly between US-1976 rows
5 to 10 km apart, which overstates density between rows.

The gates do not count rows against the input file. Each fails only on an empty row
set, so a matrix that loses rows between the reader and the sweep passes them.
