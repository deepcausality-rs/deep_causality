The corridor example logs four regime changes on its way down. The Knudsen number Kn is the gas's
mean free path divided by the body length. GNSS-denied means the plasma blocks satellite
navigation signals.

```text
regime -> slip (GNSS-available), Kn=0.07829109848665225
regime -> slip (GNSS-denied), Kn=0.012690837165407727
regime -> continuum (GNSS-denied), Kn=0.00993838892165156
regime -> continuum (GNSS-available), Kn=0.0002551442196046344
```

The blackout starts at step 131 and 73.2 km, and it ends at 46.8 km after 55.9 s. The
chemistry finds both points. No constant in the program names them.

Two pieces of code produce this. Add the classifier to the coupling, after the stages that
publish the fields it reads:

```rust
let trigger = BlackoutTrigger::new(comms_band_rad_s); // a plasma frequency above this denies GPS

Coupling::between_steps()
    // stages that publish "mean_free_path" and "n_e" come first
    .then(RegimeClassify::new(l_char, trigger))
    // later stages read the class
    .build()
```

Then read the class anywhere a `CoupledField` is in reach. The corridor pauses its march on it:

```rust
.until(|field, _| field.regime().map(|r| r.gnss_denied).unwrap_or(false))
```

## The classifier tracks two independent things

The rarefaction axis takes the peak mean free path, forms `Kn = λ / L` through
`knudsen_number_kernel`, and bands it into a `GoverningModel`. By default Kn below 0.01 is
continuum, 0.01 to 0.1 is slip, 0.1 to 10 is transitional and above 10 is free-molecular.
`with_thresholds` overrides the edges. It does not check their order.

The comms axis takes the peak electron density and maps it through the `BlackoutTrigger` to a
plasma frequency. It compares that frequency with the receiver band to set `gnss_denied`.

Both come from the evolved field every step. Nothing schedules either. From
`deep_causality_cfd/src/types/flow/corridor/regime.rs`:

```rust
impl<const D: usize, R: CfdScalar> PhysicsStage<D, R> for RegimeClassify<R> {
    fn apply(
        &self,
        _ctx: &StepContext<'_, D, R>,
        field: &mut CoupledField<R>,
    ) -> Result<(), PhysicsError> {
        let Some(mfp) = field.scalar(self.mfp_field) else {
            return Ok(());
        };
        // Rarefaction is worst where the mean free path is largest, so classify off its peak.
        let mfp_peak = peak(mfp);
        let length = Length::new(self.characteristic_length)?;
        let kn = knudsen_number_kernel(mfp_peak, &length)?;
        let model = self.model_for(kn);

        // The comms side: peak electron density → plasma frequency → GNSS-denial decision.
        let ne_peak = field
            .scalar(self.ne_field)
            .map(peak)
            .unwrap_or_else(R::zero);
        let blackout = self.trigger.evaluate(ElectronDensity::new(ne_peak)?)?;

        let class = RegimeClass {
            model,
            knudsen: kn,
            plasma_frequency: blackout.plasma_frequency,
            gnss_denied: blackout.denied,
            mach_regime: self.mach_regime_of(field),
            thrust_state: self.thrust_state_of(field),
            touchdown: self.touchdown_of(field),
        };
```

## The classifier reads two named fields

`RegimeClassify` reads `mean_free_path` and `n_e` by name. In the corridor, the example's
`FreestreamFeeds` stage publishes `mean_free_path` and the finite-rate ionization stage
publishes `n_e`. If `mean_free_path` is missing, the classifier does nothing and logs nothing.
If `n_e` is missing, it treats the electron density as zero.

## Only a change of band is logged

`RegimeClass` carries a key of five discrete values: the governing model, the denial flag, the
Mach band, the thrust state and touchdown. The key leaves out the continuous Knudsen number,
plasma frequency and Mach value. The classifier compares each step's key with the previous
step's and writes a log line only when the key changes. A Knudsen number that drifts inside one
band logs nothing.

The Mach, thrust and touchdown axes stay neutral unless you call `with_flight_axes`.

## Later stages and the march condition read the class

`TrajectoryNav` folds the GPS fix into the navigation filter only when the class says the link
is up:

```rust
let denied = field.regime().map(|r| r.gnss_denied).unwrap_or(false);
```

The march condition above reads the same flag. The chemistry therefore locates the blackout
window, and the pause that a what-if study forks from is the step where the classifier first
raised `gnss_denied`.

## The classification is a diagnostic

The crate does not switch solver closures on the class. Only the continuum band has an
implemented closure. The class drives march conditions and the navigation gate. See the
[limits page](/boundaries/#regime-diagnostic).
