import { MACHINE, MSRV } from '../../../consts';

Rust {MSRV} or newer builds the crate. The workspace `Cargo.toml` sets
`rust-version = "1.98.0"`, and crates.io lists the same minimum for the 0.3 releases.

## Add the crate to a project

```bash
cargo add deep_causality_cfd
```

To use work that has not been released, depend on the repository:

```toml
[dependencies]
deep_causality_cfd = { git = "https://github.com/deepcausality-rs/deep_causality.git", branch = "main" }
```

Use `tag` or `rev` in place of `branch` to fix the version. `rev` names an exact commit.

## Run the corridor example

The corridor example marches a compressible flow, reacts the plasma chemistry in it and cuts a
navigation filter's GPS fix while the plasma blocks the signal. It forks the marched state into
17 what-if branches and prints 13 gate results. A gate is a pass or fail check on the run's own
results. The run takes 45.9 s on {MACHINE} and exits 0 when every gate passes.

```bash
git clone --depth 1 https://github.com/deepcausality-rs/deep_causality.git
cd deep_causality
cargo run --release -p avionics_examples --example plasma_blackout_corridor
```

Run it from a checkout. The example package is part of the repository and is not published to
crates.io. Use `--release`: the committed timings come from release builds.

## Run a verification target

```bash
cargo run --release -p deep_causality_cfd --example qtt_sod
cargo run --release -p deep_causality_cfd --example dec_lid_cavity_re1000_verification trend
```

Each target checks its own results and exits nonzero when a check fails. On {MACHINE},
`qtt_sod` takes about 1 s and the cavity `trend` mode about 1 min. The
[validation page](/validation/) lists what each target asserts and to what number. The
example names are the `[[example]]` entries in `deep_causality_cfd/Cargo.toml`.

## Choose serial or parallel builds

`std` and `parallel` are both on by default. `parallel` runs sweeps and branch fan-outs
concurrently and parallelizes the loops inside the DEC solver. On small grids the coordination
costs more than the loops save. Speedup is serial time divided by parallel time. The table shows it
for the DEC marcher over a 20-step march, measured on {MACHINE}.

| Grid | Speedup |
|---|---|
| 16 × 16 | 0.31× |
| 64 × 64 | 0.82× |
| 256 × 256 | 1.04× |
| 512 × 512 | 1.47× |

Below about 256 × 256 cells, switch `parallel` off. Sweeps and branch fan-outs then run one
after another.

```bash
cargo add deep_causality_cfd --no-default-features --features std
```

The crossover depends on the hardware, so benchmark your own grid. The figures come from
`deep_causality_cfd/benches/PERFORMANCE.md` (2026-06-17).
