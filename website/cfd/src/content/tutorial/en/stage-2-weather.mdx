During blackout the navigation estimate drifts a mean 58.71 m from the true
position in polar winter, against 41.60 m on the standard day. *Drift* is how far
the estimate wanders while the vehicle flies without GPS. The program shows the gap
is real, 5.7 combined standard deviations wide.

*world*: the description of a run with one declared difference, here the
atmosphere.

## Before you start

Start it and read while it runs. It took 184.0 s on {MACHINE}.

```bash
cargo run --release -p avionics_examples --example plasma_blackout_weather
```

It flies 48 descents at once (six atmospheres times eight noise draws) and ends
with a table and eight gates. A *gate* is a pass or fail check on a result. Output
lines are wrapped for width.

## Station 1: One expression holds the whole campaign

Open `weather/main.rs`. Past the setup, the program is this:

```rust
let table = CfdFlow::study("weather-dispersion table")
    .save_log(audit_dir.join("weather.audit"))
    .cases(model::weather_cases())
    .baseline(model::standard_day)
    .alternate(model::weather_world)
    .ensemble(constants::MC_DRAWS)
    .couple(|case, draw| world::corridor_coupling(model::bias_departure(case.d_temp), draw))
    .march_for(constants::STEPS, world::initial_field)
    .reduce_ensemble(model::world_row)
    .inspect(utils_print::print_rows)
    .record(&table_path)
    .gates(model::weather_gates())
    .verdict()?;
```

Forty-eight descents, a reduction, a recorded artifact and eight acceptance
criteria read top to bottom. The type system orders the phases, so the compiler
rejects a campaign assembled out of order.

## Station 2: Six worlds share one baseline

```rust
.baseline(model::standard_day)     // the validated origin, built once
.alternate(model::weather_world)   // six counterfactual atmospheres, each marked
```

In `model.rs`, `standard_day` and `weather_world` funnel into one private
`world_cfg` builder. The baseline passes a zero temperature offset and a unit
density scale. So each world is one validated description with one declared
difference. Six independent `CompressibleMarchConfig` values would rest on the
claim that everything else matched, and a drifted constant would stay invisible.

Each world also writes a marker into its event log, naming the baseline it departs
from. This line is in the committed `cold_day` log.

```text
!!ContextAlternation!!: world 'standard_day' replaced with 'cold_day'
```

Gate 1 checks the marker in every world.

```text
[PASS] [tripwire] (1) counterfactual audit trail: every dispersion world carries the
       !!ContextAlternation!! marker naming its baseline
```

## Station 3: Eight draws give error bars and caught a false finding

```rust
.ensemble(constants::MC_DRAWS)   // 8 deterministic receiver-noise draws
```

```rust
/// Receiver-noise realizations flown per weather condition. Each draw is a deterministic
/// phase-shifted low-discrepancy sequence (no RNG dependency; draw 0 is the corridor's
/// sequence), so the whole campaign remains bit-reproducible while the drift cells gain error
/// bars. Six conditions times eight draws is 48 full descents; the scoped fan-out packs them
/// onto the available cores.
pub const MC_DRAWS: usize = 8;
```

A campaign seeded from a random number generator returns different numbers on every
run, so its gates must be loose enough to absorb the scatter. That leaves them too
loose to catch a regression. Deterministic draws keep the campaign bit-reproducible,
give error bars and keep the gates tight.

The ensemble also corrected a diagnosis. On an earlier chemistry setting, a
single-draw table showed the cold-day row 8 percent below its predicted drift, which
read like a physics finding. The eight-draw mean showed one lucky draw. One run per
condition cannot separate a mechanism from a draw.

## Station 4: The draw index and the temperature enter the physics loop

```rust
.couple(|case, draw| world::corridor_coupling(model::bias_departure(case.d_temp), draw))
```

The closure passes the case and the draw index into walk 1's coupling. The draw
index reaches the `TruthGnss` stage, which adds receiver noise to the position fix
as it is published. The temperature follows in `model.rs`:

```rust
pub fn bias_departure(d_temp: f64) -> f64 {
    1.0 + IMU_THERMAL_COEFF_PER_K * d_temp.abs()
}
```

The temperature scales the accelerometer bias the vehicle flies, while the
navigation filter keeps its standard-day priors. That mismatch between the
instrument flown and the instrument assumed is what the table measures.

## Station 5: Two gates, one for size and one for resolution

INS is the inertial navigation system, and sigma is a standard deviation.

```text
[PASS] [tripwire] (4) the INS does not behave as assumed in the cold: polar-winter mean
       blackout drift 58.71 m vs standard-day 41.60 m (1.41x; gate requires 1.2x from the
       thermal bias departure and the widened window)
[PASS] [tripwire] (4b) the cold effect is statistically resolved: polar-standard
       separation 17.11 m vs combined sigma 3.01 m (5.7 sigma; gate requires 2)
```

Gate 4 measures size: 1.41 times against a required 1.2. Gate 4b measures whether
the effect is resolved: 17.11 m must clear two combined standard deviations, and it
clears 5.7. Without 4b, a scatter of 15 m would make that separation meaningless,
yet gate 4 would pass. The `save_log` phase flushes the audit files step by step, so
a campaign that dies at draw 40 of 48 still leaves the evidence for the 40 that
finished.

## Try it yourself

**1. Weaken the statistics.** Set `MC_DRAWS` to `2`. Watch the combined sigma, and
check whether gate 4b still clears 2 sigma.

**2. Add a condition.** Add a row to `WEATHER` in `constants.rs` and change the
array length from 6 to 7, for example `("very_cold_day", -55.0, 1.30)`. Check
whether gate 3, the spread in blackout start, changes.

**3. Trace one row.** Open a drift cell's eight files in `weather/audit/` and confirm
that each names the baseline it departs from.

## What this walk established

- Fork a paused state to share a past. Change the world to share a description.
- Deterministic draws give error bars and reproducible runs.
- A row needs an ensemble to separate a mechanism from a draw.
