Yes. The circuit version reaches the same plan at cost 2 and the same survivor, H1. Only the way
the candidates are written changes: in [the first example](/examples/qcl-crosstalk/) each
structure is declared as a factorization, and here the wiring of a circuit carries it.

## What you see

```text
[build] the cyclic circuit H4 Q1->Q2->B->Q1
    ✓ refused at build(): the circuit's grouping wires a node into another and back; ...

[validate] two circuits, each screened through its dilation
    H1 Q1->Q2    2 nodes, edges [(0, 1)]; stages: check_markov Accepted, check_decomposable Vacuous
    H2 Q2->Q1    2 nodes, edges [(1, 0)]; stages: check_markov Accepted, check_decomposable Vacuous
    H3 Q1<-B->Q2 kept as the v1 factorization (see model.rs)
...
    plan: ["E1 do(Q1=|1>) P(e2)", "E2 do(Q2=|1>) P(e1)"]  total cost 2   (tomography alone would cost 200, 100× more)
    covers every pair: yes   costs 2: yes   picked both interventions: yes
...
[adjudicate] H1 Q1->Q2 survives, 100.1 bits from its nearest rival. Direct cause, not shared bath.
    the adjudication named the structure the observation came from: yes
```

## How the structure travels

| Candidate | Form | How the structure is carried |
|---|---|---|
| H1, Q1 → Q2 | one wire, Q1's box then Q2's | the wire leaves node 0 and enters node 1 |
| H2, Q2 → Q1 | the same boxes, Q2's first, grouped so node 0 stays Q1 | the wire leaves node 1 and enters node 0 |
| H3, Q1 ← B → Q2 | the factorization from the first example | declared supports |
| H4, Q1 → Q2 → B → Q1 | four boxes on one wire grouped into a cycle | refused at `build()` |

Each circuit goes through `over_circuit`, and the structural stages screen its dilation. The
dilation's normalised factors then become the candidate that the plant pipeline forks. The
decomposability check reads Vacuous on the two circuits because a two-node structure holds no
3×3 sub-relation.

## Read before you cite

The bath candidate H3 stays a factorization. A bath that drives two qubits needs a node with two
output wires, and under the dilation's leg convention that node has a leg of 256 dimensions. The
Markov union over its three legs is a 65536 × 65536 matrix with 2<sup>32</sup> entries, which is
beyond the crate's cap of 2<sup>24</sup>. The read-outs, the observation and the cost unit carry
the same caveats as in the first example.
