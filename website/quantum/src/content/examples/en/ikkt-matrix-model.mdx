The action falls from 0.048 to 0.00000082 in 40 steps while the configuration norm stays at
1.356465997, so the matrices came to commute and did not shrink. The IKKT model is a candidate
non-perturbative formulation of type IIB superstring theory. It contains no spacetime of its own.

The action is `S = Σ ‖[X_μ, X_ν]‖²`, which is zero exactly when every pair of matrices commutes.
Commuting matrices diagonalise together, their joint eigenvalues form a set of points, and that
set is the emergent spacetime.

## Why the norm is held fixed

The action is quartic in the coordinates. Multiplying every matrix by 1 − η multiplies the action
by (1 − η)⁴ whatever the matrices do, so a run that shrinks everything toward the origin reports
an action falling smoothly to zero and demonstrates nothing. Each step here restores the starting
norm, so the action can fall only if the matrices commute.

## What it takes from this crate

Only `commutator_kernel`, the `Operator` alias and `QuantumError`. The equation of motion takes
two nested calls to the kernel. The kernel returns a `Result`, so a metric mismatch between two
operands is a named failure at the point it happens, and never a silently wrong matrix inside the
action. The geometric algebra comes from `deep_causality_multivector`.
