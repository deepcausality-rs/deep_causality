The syndrome. A bit flip on qubit 1 of the three-qubit repetition code is undone with fidelity
1.000000000 when the decoder reads the syndrome the measurement produced. When an intervention
forces the syndrome to point at qubit 0, the decoder corrects the wrong qubit and the fidelity is
0.000000000. Substituting the
syndrome and watching the recovery follow shows that the syndrome causes the recovery.

A lone qubit cannot be checked, because any measurement that would reveal a flip also reveals the
amplitudes and collapses the superposition. The code spreads one logical qubit over three and
measures only parities. A parity such as `⟨Z0 Z1⟩` is exactly +1 or −1 whatever the amplitudes are.

## The forced syndrome corrects the wrong qubit

```text
Encoding
  logical      0.600|0> + 0.800|1>
  encoded      0.600|000> + 0.800|111>
...

The error: an X gate on qubit 1
  before       0.600|000> + 0.800|111>
  after        0.600|010> + 0.800|101>
...

The syndrome: two parity measurements
  check        clean      corrupted
  <Z0 Z1>     +1.000       -1.000
  <Z1 Z2>     +1.000       -1.000
...

Recovery from observed
  syndrome     (differ, differ)  ->  qubit 1
  state        0.600|000> + 0.800|111>
  fidelity     1.000000000

Recovery from do(syndrome := qubit 0)
  syndrome     (differ, agree )  ->  qubit 0
  state        0.600|110> + 0.800|001>
  fidelity     0.000000000
```

The `X` gate on qubit 1 moves amplitudes between basis states, so norm² stays 1.000000000. The
parity rows read exactly +1.000 or −1.000 and carry no trace of the amplitudes 0.6 and 0.8, because
every basis state in a code word agrees on the parity of any two qubits. The corrupted register
gives (differ, differ), which the decoder's table maps to qubit 1, and `X` there restores the
encoded state. In the second run the syndrome (differ, agree) points at qubit 0, and `X` there turns
`0.600|010> + 0.800|101>` into `0.600|110> + 0.800|001>`, a normalised state orthogonal to the
protected one. Applying no correction at all also gives fidelity 0.000000000.

## One line separates the two pipelines

The two pipelines start from the same corrupted register and differ by one line:

```text
observed        measure →                      recover
counterfactual  measure → do(syndrome := q0) → recover
```

`alternate_value_if` is the do-operator. When the measured syndrome flags an error
(`Syndrome::is_error`), it replaces the syndrome with the value an intervention forces, here
`NAMES_QUBIT_0`, and it records the substitution. The recover stage reads the syndrome and nothing
else, so the substitution changes everything the decoder has to go on. Norm cannot tell the two
recoveries apart, since both end in a normalised state; the fidelity to the protected state does.

## The run covers one bit flip on one known qubit

The run applies one bit flip to one known qubit, so it covers no phase errors. It reads each parity
as an expectation value, with no sampling, no collapse and no ancilla qubits, and the decoder is a
four-row lookup. The intervention forces one syndrome, (differ, agree); the run does not try the
others.

This example does not import `deep_causality_quantum`. The register is a multivector from
`deep_causality_multivector`, and the effect plumbing comes from `deep_causality_core`.
