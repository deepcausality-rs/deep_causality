The recovery is caused by the syndrome, and the run shows it by substituting the syndrome and
watching the recovery follow. Reading the syndrome the measurement produced restores the state
with fidelity 1. Reading a syndrome that an intervention forced gives fidelity 0.

A lone qubit cannot be checked, because any measurement that would reveal a flip also reveals the
amplitudes and collapses the superposition. The repetition code spreads one logical qubit over
three and asks only how the three relate, which a parity measurement answers with exactly +1 or
−1 whatever the amplitudes are.

## What you see

```text
Encoding
  logical      0.600|0> + 0.800|1>
  encoded      0.600|000> + 0.800|111>
...

The error: an X gate on qubit 1
  before       0.600|000> + 0.800|111>
  after        0.600|010> + 0.800|101>
...

The syndrome: two parity measurements
  check        clean      corrupted
  <Z0 Z1>     +1.000       -1.000
  <Z1 Z2>     +1.000       -1.000
...

Recovery from observed
  syndrome     (differ, differ)  ->  qubit 1
  state        0.600|000> + 0.800|111>
  fidelity     1.000000000

Recovery from do(syndrome := qubit 0)
  syndrome     (differ, agree )  ->  qubit 0
  state        0.600|110> + 0.800|001>
  fidelity     0.000000000
```

## The counterfactual

The two pipelines run the same four steps on the same corrupted register and differ by one line:

```text
observed        measure →                      recover
counterfactual  measure → do(syndrome := q0) → recover
```

`alternate_value_if` is the do-operator. It replaces the measured value with the value an
intervention forces, and it records the substitution. The wrong correction leaves a state
orthogonal to the one being protected: no worse in norm, and no use at all.

## Crates

This example does not import `deep_causality_quantum`. The register is a multivector from
`deep_causality_multivector`, and the effect plumbing comes from `deep_causality_core`.
