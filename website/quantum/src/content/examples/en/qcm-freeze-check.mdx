Only when its factors commute: `σz` with `diag(3, −1)` freezes cleanly, and `σx` with `σz` aborts
the freeze at nodes 0 and 1 and leaves the graph dynamic. A graph is a quantum causal model only
when the factors that share a Hilbert leg (one qubit's space) commute pairwise, and
`freeze_quantum` tests that condition at the moment the graph turns from dynamic to frozen. The
example freezes one two-node graph with each of the two factor pairs.

## Diagonal factors freeze; σx and σz abort

```text
[1] sigma_z and diag(3, -1) on leg 0
    expected: they commute
    froze cleanly
      pairs tested       1
      worst margin       0.000e0
      is_frozen()        true
...

[2] sigma_x and sigma_z on leg 0
    expected: they anticommute
    freeze aborted
      offending pair     nodes 0 and 1
      reason             ‖[ρ_0, ρ_1]‖_F exceeds the Q-TOL threshold (margin > 1)
      is_frozen()        false
...
```

Both factors sit on leg 0, so each run tests one pair. In run 1 the margin is the commutator's
Frobenius norm divided by the threshold, and 0.000e0 means the commutator is zero: two diagonal
matrices commute exactly. In run 2 the commutator `[σx, σz] = −2iσy` has norm 2√2, far above a
threshold that scales with the scalar's unit roundoff. The margin exceeds 1, the freeze aborts, and
`is_frozen()` reads false because the graph has rolled back to dynamic.

## At the freeze the structure is complete and unused

A check there never rejects a half-built graph and never finds the problem after a result has been used. A failure costs the
caller a rebuild.

The error carries `QuantumErrorEnum::CommutatorNonZero { node_j, node_k, detail }`, so the caller
receives the node indices as data.

## The run checks commutativity only

The example passes `None` for the faithfulness argument, so only the commutativity check runs;
supplying the declared inputs and outputs adds the C₃ check over the frozen graph. The check is
sound, since it never accepts a non-commuting model, and it may be incomplete. The run tests one
pair of hand-written 2×2 factors on one leg, with the default tolerance (safety factor 8, unit
roundoff equal to the scalar's epsilon).

The example imports `deep_causality_quantum` for `freeze_quantum`, `CommutatorTolerance`,
`ProcessFactors` and `FactorSupports`, and `deep_causality` for the graph.
