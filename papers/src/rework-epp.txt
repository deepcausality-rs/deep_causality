================================================================================
1. THE REPAIRED CORE THESIS
================================================================================

Thesis:

    The monad carries the process. The term carries the structure. Autonomy carries the causal
    content.

    A causal model is a term: a chain or graph of named steps, each autonomous and dependent. It is
    not the value or the arrow the term composes to.

    Form:         m2 = m1 >>= f, the composition law of the process. It is not the definition of
                  causation.
    Term:         the named steps and their wiring. Two terms with the same composite can be
                  different causal models. The monad laws equate evaluations, and they do not by
                  themselves establish that two models are the same.
    Autonomy:     f reads only what bind threads to it, and it stays invariant when other mechanisms
                  are replaced. Locality is structural. Stability is postulated by the modeller.
    Dependence:   the output of f changes with at least one input channel, ignoring the log.

Why the term is required: the chains [id, not] and [not, id] compose to the same arrow and answer
differently when the middle value is forced. So a composite arrow cannot determine an intervention.
This agrees with the literature, which places interventions on syntax: Jacobs, Kissinger and Zanasi
perform surgery in the syntactic category, and Wang et al. say causal programs must expose more of
their intension than probabilistic ones.

A monad can express causal models. Stoch is the Kleisli category of the Giry monad, and the Caus monad
of Wang et al. handles interventions and counterfactuals. No paper found states that monads cannot
define causation, and none uses one to define it. The trap is treating the monad as the definition.

What this gives:

  - An answer to the objection that the axiom admits every program. The form admits every program, and
    that is acceptable, because the form is not the definition.

  - The deterministic biconditional becomes a theorem. Dependence on a bivalent input and output
    forces f = id or f = not. The current text assumes the biconditional as a restriction.
  - Autonomy licenses reading f(0) as "what E2 would have been had E1 not happened". Without it,
    f(0) = 0 is only a value in a table.
  - For a pinned unit u, substituting a value and re-running the same mechanisms computes Y_x(u),
    which is Pearl's unit-level counterfactual.
  - Causal direction is defined without time: forcing E1 moves E2, and forcing E2 leaves E1 alone.
    bind alone does not supply this, because the identity is invertible.
  - Chains match Lewis: dependence holds per step and causation is the chain, since dependence does
    not compose.

What the thesis gives up:

  - "Strict generalization of the SCM". A deterministic stateful run unrolls into a time-indexed
    SCM, so the gain looks structural rather than expressive. Keep the claim only if it is proved.
  - "Counterfactuals without abduction" as a general statement. The correct form is: abduction is
    unnecessary when u is known. With partial evidence, P(U|e) is still required.
  - "Classical causality is recovered" as a claim about Pearl. The biconditional is deterministic
    necessary-and-sufficient causation, a narrow special case of his framework.
  - Selection claims: "Not Possible", "only viable option", and any "first" or "uniquely".
  - Any claim that verified causality is an empty niche. Makhija, Zhang et al. and Sargsyan refute it.
  - Any claim that the syntax and semantics split is new. It is the established move of Jacobs et al.
    and the Markov-category line, and the EPP aligns with it.

What is new and worth a scholar's attention:

  - An executable process term with state, error and audit-log channels. Every monadic precedent found
    has a probability structure as its carrier. That is an absence in a limited search, so word it so.
  - The context as a substitutable channel, separate from mechanism and state.
  - Direction without temporal precedence.
  - Mechanisms that change at runtime inside one typed process, with an append-only audit log.
  - Verification moved to the action layer where the structure itself may change.

What stays a postulate, permanently: stability of a mechanism. No proof can establish it for a real
system. Pearl's modularity has the same status, and the LaTeX already says so. State it in the status
table rather than implying that formal verification covers it.

All references are to papers/src/EPP/epp_chapters/causality_as_epp.tex unless noted.

2.1 Attribution of the classical definition (section "Classical Definition of Causality", line 41)
    Problem: the biconditional is attributed to Pearl, along with temporal precedence.
    Fix: present it as deterministic necessary-and-sufficient causation. Cite Hume's second
    definition and Lewis for the counterfactual reading, and Pearl's probability of necessity and
    sufficiency equal to 1 as the link. Pearl does not require temporal precedence.
    Check these three citations against the sources. They are from memory.

2.2 The monad preliminaries (line 173)
    Problem: the text gives a triple with unit T to M<T>. In the model the Kleisli unit is
    eta : Option V -> S -> Option C -> Process, and pure' resets state and clears context, so it is
    not a right unit. Lean's Core/CausalMonad.lean states this distinction.
    Fix: state the laws as Lean proves them, with the two units named.

2.3 The unit context and Proposition 1 (lines 186 to 200)
    Problem: "under the unit context M is isomorphic to the identity monad, regardless of n" is
    false. The error channel is a sum, so Result<V, ()> is Maybe V. Option<Context> at unit has two
    inhabitants, and the absent value and the command layer add more. At V = Empty the identity has
    no inhabitant and the carrier does.
    Fix: drop the unit context. In every instance bind(eta(v), lift g) = eta(g v), by left identity,
    and eta is injective. So pure functions embed faithfully in the Kleisli category, and the theorem
    gets stronger. Checked in Lean: unit_context_not_identity, pure_embeds, lift_comp, eta_injective.

2.4 Proposition 2 (line 213)
    Problem: it is true and vacuous. Restriction 2 restates the classical definition, so the argument
    has the form "A and C imply C".
    Two tests show the gap:
      - Constants. The bare form admits four functions on {0,1}. The classical definition rejects
        the two constants, and a constant can be local and stable, so autonomy does not exclude it.
        The current definition is therefore not conservative over the classical one.
      - The barometer. "Storm iff low reading" satisfies Proposition 2 as written, because the proof
        never uses autonomy.
    Fix: add dependence to the definition, then derive the biconditional. Restate the proposition
    with autonomy as a premise. Checked in Lean: bivalent_dependence, constant_not_dependent,
    same_observations, different_interventions.
    Dependence must range over all input channels. Many examples ignore the value and read the
    context, so a value-only clause would reject them.

2.5 Dependence does not compose
    f(0)=0, f(1)=1 and g(0)=g(1)=0, g(2)=1 are both dependent, and g after f is constant. So causal
    steps do not form a subcategory. Dependence is a per-step predicate on arrows, and the ambient
    category stays the Kleisli category. Checked in Lean: dependence_not_closed.

2.6 Direction (section "Generalized Definition", line 108)
    Problem: "the directional flow of bind is the propagation condition". The identity is invertible,
    so bind's direction is syntax. Checked in Lean: biconditional_symmetric.
    Fix: define direction by intervention asymmetry and cite Proposition 3 as the tool.

2.7 The intervention operator (line 231)
    Three mismatches with the code, where the code and Lean are right:
      - The paper's error case extends the log. alternate_value returns unchanged, and Lean proves
        value_error_noop.
      - The tuple holds a value and an error separately. The carrier holds them in one channel.
      - The name intervene no longer exists as a function. It is alternate_value.
    Fix: rewrite the definition from the Rust and Core/Alternatable.lean.

2.8 Proposition 3 (line 242)
    Problem: "exactly the effect of do" conflicts with the code comments and Lean, which say that
    substitution is not do. It holds only on a chain whose later steps read the value channel. In a
    DAG, replacing the whole value discards sibling variables.
    Fix: scope it to chains, name alternate_value, and align the core comments with the wording. For
    records, state the component update form. Graph do becomes its own theorem, section 3.1.

2.9 Two axioms in one monograph
    epp_chapters/formalization.tex line 43 still states the axiom as
    "for all c, there exists f with c = (E2 = f(E1))", with E and f unconstrained. Chapter 4 states
    the monadic form. Section 12.3 and the introduction still use the functional wording, and the
    universal form cannot be falsified.
    Fix: one definition, stated once, in the repaired form above.

2.10 The ladder mapping (lines 623 to 700, and formalization.tex from line 747)
    - Rung 1 is called association but runs mechanisms forward, which is do semantics. State it as
      forward evaluation, and give conditioning its own treatment under P(U).
    - Rung 2 is mapped to a CSM action, which changes external state. That is an action, not model
      surgery. Map rung 2 to graph do.
    - "Abduction is Context Pinning" holds only when the context fully determines u. Checked in Lean:
      abduction_needs_pinned_u.

2.11 Rubin and Granger sections
    - "The fundamental problem of causal inference is a physical constraint" reads as a dismissal.
      Computing both outcomes from a stipulated model does not address estimation from data. Say so.
    - Granger's test is predictive, not "fundamentally counterfactual". It also needs a statistical
      test; comparing one forecast error is not one.

2.12 Appendix A (epp_appendices/appendix_a.tex)
    Unchanged since May 3. Three faults:
      - Case 1 computes P(Y|X=x) by setting X and propagating, which is do(X=x). With a confounder
        the two differ: P(Y=1|X=1) = 1 against P(Y=1|do(X=1)) = 1/2 in the checked example.
      - U is mapped to values, so P(U) is absent and the semantics are not probabilistic.
      - There is no counterfactual case, and its do relies on a priority check hand-written into a

    Replacement, in two steps:
      Unit level. For fixed u, running with context u and substituting x computes Y_x(u).
      Population level. Pushing P(U) through gives rungs 1 and 2. Rung 3 needs P(U|e).
    Remove "strict generalization" unless a separating model is exhibited.

2.13 The form is presented as the definition
    Problem: the axiom is introduced as the definition of causation. The autonomy section (line 135)
    already says bind is necessary but not sufficient, and its definition at line 154 still names a
    monadic composition rather than a model.
    Fix: define the causal model as the term, per section 1, and state that the monad laws do not
    identify models. Then define when two terms are the same model (4.3 T1). Without that definition

2.14 Claims to remove

    The do operator is a real gap and must be added. Nothing in this section is a decision. It records
    what the code establishes and what the design has to answer. Design comes before any code.

    What the code establishes:
      - deep_causality_core has only value, context and state substitution in

        Saigo, and with Makhija.
    T2. Bridge theorem. The monad laws preserve model identity when the named steps are preserved. This
        connects the monad to the term, and the thesis depends on it.

    b. Structural model and submodel. Define a finite acyclic SCM, its submodel M_x and Y_x(u).

       Associativity must be addressed here. Di Lavore, Román and Széles show normalization forces

       bind step, or must sit outside the monad laws, for example as an unnormalized value with
       normalization at the boundary. Deterministic chains are unaffected.
    e. Markov-category bridge. With a probability monad on the value channel, the Kleisli category

    f. Direction by intervention asymmetry on a chain.
    g. Ethos determinism and confluence of resolve_conflicts. Small and worthwhile, since the Ethos

================================================================================
5. STRUCTURE OF THE CORE PAPER
================================================================================

A short theorem paper, separate from the monograph. Target 15 to 20 pages.

Title and abstract say what it is: an operational semantics for causal processes with known
mechanisms, conservative over deterministic SCMs at the unit level, with machine-checked proofs. The
central statement: the monad carries the process, the term carries the structure, and autonomy carries
the causal content.
Avoid "post-quantum", "axiomatic foundation of causality" and "generalizes classical causality".

 1. Introduction
    A problem Pearl's readers recognize: a process whose mechanisms switch at runtime. The first page
    states the scope: mechanisms are known; discovery and identification from data are out of scope;
    existing tools supply the graph. Section 4.12.5 of the current text already says this.

 2. Background
    SCM, submodel M_x, Y_x(u), modularity, in standard notation. Kleisli categories, in one page.

 3. Definition
    The carrier as Lean states it. The form, the term, autonomy and dependence. Why a composite arrow
    cannot determine an intervention. Term equivalence, and the bridge theorem to the monad laws. One
    definition, stated once.

 4. Recovering the deterministic case
    Pure functions embed. Dependence gives the biconditional. Autonomy gives the counterfactual
    reading. Direction by intervention.

 5. Correspondence with the SCM
    Chain substitution. Graph do equals M_x. Unit-level Y_x(u). Population lift. Exactly where
    abduction is still required. A table of what is recovered and what is not.

 6. What the process view adds
    Lead with the comparison against Caus and ChiRho, the nearest systems. Then the context as a
    substitutable channel, runtime mechanism change and audit. State what each gives beyond a reader
    monad over probability, an SCM with time-indexed variables, or effect handlers, and concede where
    it only gives convenience.

 7. Worked example
    One confounded system with a regime change, not a stipulated constant. Show P(Y|x), P(Y|do(x)),
    a unit counterfactual, and the mechanism switch. Runnable, with its output in the paper.

openspec/notes/archive/quantum/quantum-epp.md says so: the algebra is the Kleisli category of the
causal monad, "directional, irreversible, copy-ful", and no-cloning is the absence of a copy
structure. Only 4 of the 104 source files in deep_causality_quantum use the monad, and the README
keeps factors as static freeze-time data. Quantum nesting is unestablished, against the recursive
encapsulation of section 4.7, and the crate refuses cycles where section 12.3 predicted superposed
graphs.

The defensible version: the classical and quantum boundary is the Kleisli boundary. Separating
mechanism from world, plus the freeze boundary, gave Lorenz's checks a natural home, and classical
control runs around the quantum core in the monad. No written conjecture linking the monad to QCM was
found. A construction where quantum channels compose through bind without copying would change this
assessment.

/- Scratch: machine check of the repaired EPP reconstruction. Self-contained, no Mathlib.
   `Process`, `eta`, `bind'` transcribe lean/DeepCausalityFormal/Core/CausalMonad.lean. -/
namespace EppRepair

structure Process (V S C E L : Type) where
  outcome : Except E (Option V)
  state : S
  ctx : Option C
  logs : List L

variable {V W X S C E L : Type}

def eta (v : Option V) (s : S) (c : Option C) : Process V S C E L :=
  { outcome := .ok v, state := s, ctx := c, logs := [] }

def bind' (m : Process V S C E L) (f : Option V → S → Option C → Process W S C E L) :
    Process W S C E L :=
  match m.outcome with
  | .error e => { outcome := .error e, state := m.state, ctx := m.ctx, logs := m.logs }
  | .ok v =>
    let n := f v m.state m.ctx
    { outcome := n.outcome, state := n.state, ctx := n.ctx, logs := m.logs ++ n.logs }

/-! ## 1. Proposition 1: the stated reason is false, the conclusion holds without it -/

/-- The unit context is NOT the identity monad: at `V = Empty` the identity has no inhabitant
    and the carrier has one. So "unit parameters give the identity monad" is false. -/
theorem unit_context_not_identity :
    Nonempty (Process Empty Unit Unit Unit Unit) ∧ ¬ Nonempty Empty :=
  ⟨⟨{ outcome := .error (), state := (), ctx := none, logs := [] }⟩, fun ⟨e⟩ => nomatch e⟩

/-- A pure function lifted into the carrier. -/
def lift (g : Option V → Option W) : Option V → S → Option C → Process W S C E L :=
  fun v s c => eta (g v) s c

/-- Proposition 1, repaired: holds at EVERY state, context, error and log type. -/
theorem pure_embeds (g : Option V → Option W) (v : Option V) (s : S) (c : Option C) :
    bind' (eta v s c : Process V S C E L) (lift g) = eta (g v) s c := by
  simp [bind', eta, lift]

/-- The embedding preserves composition. -/
theorem lift_comp (g : Option V → Option W) (h : Option W → Option X)
    (v : Option V) (s : S) (c : Option C) :
    bind' (lift g v s c : Process W S C E L) (lift h) = lift (h ∘ g) v s c := by
  simp [bind', eta, lift]

/-- The embedding is faithful: stripping the unit is sound. -/
theorem eta_injective (v w : Option V) (s : S) (c : Option C)
    (h : (eta v s c : Process V S C E L) = eta w s c) : v = w := by
  simp [eta] at h
  exact h

/-! ## 2. Proposition 2: dependence derives the biconditional -/

def Dep {A B : Type} (f : A → B) : Prop := ∃ x y, f x ≠ f y

/-- On a bivalent domain, dependence is exactly the two admissible functions. -/
theorem bivalent_dependence (f : Bool → Bool) : Dep f ↔ (f = id ∨ f = not) := by
  constructor
  · rintro ⟨x, y, hxy⟩
    cases h0 : f false <;> cases h1 : f true
    · cases x <;> cases y <;> simp_all
    · exact Or.inl (by funext b; cases b <;> simp_all)
    · exact Or.inr (by funext b; cases b <;> simp_all)
    · cases x <;> cases y <;> simp_all
  · rintro (rfl | rfl)
    · exact ⟨true, false, by decide⟩
    · exact ⟨true, false, by decide⟩

/-- The bare form admits constants, which the classical definition rejects. -/
theorem constant_not_dependent (b : Bool) : ¬ Dep (fun _ : Bool => b) := by
  rintro ⟨_, _, h⟩; exact h rfl

/-- Dependence does not compose, so it must be stated per step. -/
theorem dependence_not_closed :
    ∃ (f : Bool → Fin 3) (g : Fin 3 → Bool), Dep f ∧ Dep g ∧ ¬ Dep (g ∘ f) := by
  refine ⟨fun b => if b then 1 else 0, fun n => n == 2, ⟨true, false, by decide⟩,
    ⟨2, 0, by decide⟩, ?_⟩
  rintro ⟨x, y, h⟩
  cases x <;> cases y <;> exact h (by decide)

/-- `id` is its own inverse, so the biconditional carries no direction. -/
theorem biconditional_symmetric (a b : Bool) : b = id a ↔ a = id b := by
  simp [eq_comm]

/-! ## 3. Why autonomy is required: same observations, different interventions -/

/-- Common cause: pressure sets both. -/
def stormCommon (z _baro : Bool) : Bool := z
/-- Chain: the barometer sets the storm. -/
def stormChain (_z baro : Bool) : Bool := baro

/-- Both models satisfy the biconditional "storm iff low barometer" on every unit ... -/
theorem same_observations (z : Bool) :
    stormCommon z z = z ∧ stormChain z z = z := ⟨rfl, rfl⟩

/-- ... and they disagree under intervention. No property of observed `f` separates them. -/
theorem different_interventions :
    ∃ z b, stormCommon z b ≠ stormChain z b := ⟨true, false, by decide⟩

/-! ## 4. Appendix A: setting and propagating is `do`, not conditioning -/

def units : List Bool := [true, false]
def xOf (u : Bool) : Bool := u
def yOf (u : Bool) : Bool := u

def count (p : Bool → Bool) : Nat := (units.filter p).length

/-- P(Y=1 | X=1) as a pair (numerator, denominator). -/
def conditional : Nat × Nat :=
  (count (fun u => xOf u && yOf u), count (fun u => xOf u))
/-- P(Y=1 | do(X=1)): Y's mechanism ignores X here, so forcing X leaves Y to U. -/
def interventional : Nat × Nat :=
  (count (fun u => yOf u), units.length)

theorem conditioning_differs_from_do :
    conditional = (1, 1) ∧ interventional = (1, 2) := by decide

/-! ## 5. Unit-level counterfactuals are exact; abduction needs u pinned -/

/-- A two-node structural model with exogenous `U`. -/
structure Scm (U : Type) where
  fx : U → Bool
  fy : U → Bool → Bool

/-- Pearl's unit-level counterfactual: solve the submodel with X replaced by x. -/
def Scm.yUnderDo {U : Type} (m : Scm U) (u : U) (x : Bool) : Bool := m.fy u x

/-- Transcribes `alternateValue` in Core/Alternatable.lean: the entry `a` is the audit marker. -/
def setValue (a : L) (m : Process V S C E L) (v : V) : Process V S C E L :=
  match m.outcome with
  | .error _ => m
  | .ok _ => { m with outcome := .ok (some v), logs := m.logs ++ [a] }

/-- The paper's first `intervene` case is false for the code: an errored carrier is returned
    unchanged, so the log does not grow. -/
theorem setValue_error_noop (a : L) (m : Process V S C E L) (v : V) (e : E)
    (h : m.outcome = .error e) : setValue a m v = m := by
  simp [setValue, h]

def stepX {U : Type} (m : Scm U) (_ : Option Unit) (s : Unit) (c : Option U) :
    Process Bool Unit U E L :=
  { outcome := .ok (c.map m.fx), state := s, ctx := c, logs := [] }

def stepY {U : Type} (m : Scm U) (v : Option Bool) (s : Unit) (c : Option U) :
    Process Bool Unit U E L :=
  { outcome := .ok (do let u ← c; let x ← v; pure (m.fy u x)), state := s, ctx := c, logs := [] }

/-- Pinned context, value substitution, same mechanism: exactly `Y_x(u)`. -/
theorem counterfactual_unit_level {U : Type} (a : L) (m : Scm U) (u : U) (x : Bool) :
    (bind' (setValue a (bind' (eta (some ()) () (some u) : Process Unit Unit U E L) (stepX m)) x)
      (stepY m)).outcome = .ok (some (m.yUnderDo u x)) := by
  simp [bind', eta, stepX, stepY, setValue, Scm.yUnderDo]

/-- Evidence does not pin `u`: two units agree with X=1, Y=1 and answer differently at x=0. -/
def twoExo : Scm (Bool × Bool) :=
  { fx := fun _ => true, fy := fun u x => if x then u.1 else u.2 }

theorem abduction_needs_pinned_u :
    ∃ u v : Bool × Bool,
      twoExo.fx u = true ∧ twoExo.yUnderDo u true = true ∧
      twoExo.fx v = true ∧ twoExo.yUnderDo v true = true ∧
      twoExo.yUnderDo u false ≠ twoExo.yUnderDo v false :=
  ⟨(true, true), (true, false), rfl, rfl, rfl, rfl, by decide⟩

/-! ## 6. Whole-value substitution discards a sibling in a DAG -/

/-- Value carries (z, x); Y reads both. Replacing the whole value with a stale z changes Y. -/
def yFork (p : Bool × Bool) : Bool := p.1 && p.2

theorem component_update_required :
    let factual : Bool × Bool := (true, false)
    yFork (factual.1, true) ≠ yFork (false, true) := by decide

end EppRepair

#print axioms EppRepair.counterfactual_unit_level

/- Scratch: a composite Kleisli arrow does not determine the result of a mid-chain intervention.
   Same arrow after composition, different counterfactual. Identity monad suffices. -/
def chainA : List (Bool → Bool) := [id, not]
def chainB : List (Bool → Bool) := [not, id]
def run (c : List (Bool → Bool)) (x : Bool) : Bool := c.foldl (fun v f => f v) x
/-- Force the value after step 0, then run the remaining steps. -/
def runDo (c : List (Bool → Bool)) (forced x : Bool) : Bool :=
  (c.drop 1).foldl (fun v f => f v) (let _ := x; forced)
theorem same_composite : ∀ x, run chainA x = run chainB x := by decide
theorem different_intervention : runDo chainA true false ≠ runDo chainB true false := by decide
#print axioms same_composite
#print axioms different_intervention
